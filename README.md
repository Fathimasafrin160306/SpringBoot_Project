# Student Management System

A Java web-based Student Management System built using **Java, Hibernate ORM, Jakarta Servlet, JSP, Maven, MySQL, and Apache Tomcat**. The application allows users to register student details and view all registered students through a simple and responsive web interface. Hibernate is used for database persistence, while Servlets handle the application logic and JSP provides the user interface.

### Features

* Add/register student details
* Store student data in MySQL
* Retrieve and display registered students
* Hibernate-based database persistence
* Servlet-based request handling
* Responsive and enhanced user interface
* Maven-based project structure
* Runs on Apache Tomcat

### Technologies Used

**Java | Hibernate 6 | Jakarta Servlet | JSP | Maven | MySQL | Apache Tomcat | HTML | CSS**
